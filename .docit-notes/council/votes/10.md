## Voting Notes

### License (N00-1, N01-2, N03-2, N04-1, N05-3, N10-4, N11-1) — P1 UNANIMOUS

All instances of the license mismatch merit admission and P1 priority. Cartographer and Skimmer both flagged this as the single highest-trust risk above the fold. From a discoverability lens, an unresolved license is a red flag that blocks enterprise adoption, awesome-list inclusion, and institutional trust. Without this resolved, the entire launch fails. I co-sign the Cartographer's merger: one P1 issue, not seven. The veto on "MIT advertised as adopted" stays armed until `LICENSE` contains a real SPDX grant.

### Hero Alignment (N01-1, N01-4, N03-1) — P1 UNANIMOUS

Skimmer's three hero nominations (tagline revision, marketplace caveat, license) are all blocking the first-10-seconds promise. Tagline and marketplace caveat are Phase 3 revisions not yet landed in the README — they're ready to paste. These are admission + P1.

### Marketplace Install Caveat Consensus (N01-4, N02-2, N03-1, N11-4) — P1 UNANIMOUS

Four personas independently nominated the same issue: the README install block lacks the "Git URL / local clone; marketplace unverified" caveat. Cartographer rated this a merge-into-one-issue P1. Consensus across Skimmer (hero layer), Adopter (quickstart), Skeptic (positioning), and Amplifier (launch) is strong. Admission + P1.

### `codify`/`review` Missing from CHANGELOG (N04-3, N09-1, N11-2) — P1 UNANIMOUS

Cartographer, Evaluator, Returning User, and Amplifier all flag this: `codify` and `review` shipped in the unreleased window but are absent from `CHANGELOG.md`. This breaks honest-hype on the front door. Two signatures in git log (`6ea36a7`, `de7b9f9`) verify they're in the repo; the changelog must reflect them. Admission + P1.

### Skill Layout Spec Conflict (N05-5, N06-B, N07-1, N08-5) — P1 CONSENSUS, BLOCKING

Four personas converge on the same blocking inconsistency: `CONTRIBUTING.md` vs. `skills/write-a-skill/SKILL.md` specify conflicting optional directory structures. This blocks `write-a-skill` how-to, the skill-anatomy diagram, and contributor onboarding. Cartographer correctly frames this as a decision + ADR (not four independent issues). Admission + P1 for the *decision* issue; downstream how-to and diagram are P2 (unblocked-after).

### Philosophy/Enforcement-Model/Authorship-Crews (N05-1, N05-2, N05-4, N06-A, N06-E, N06-G) — P1/P2 CONSENSUS

These three explanation docs are tightly coupled: philosophy asserts "enforcement over aspiration" but `enforcement-model.md` doesn't exist (Cartographer veto: can't ship philosophy without supporting rationale). Authorship-crews doc is required for mode-correct linking from philosophy principle 6. All three merit admission; philosophy + enforcement-model are P1 (blocking); authorship-crews + cross-link are P2 (high-priority dependencies).

### `list-skills` Undercounting (N00-2, N01-3, N03-4, N05-7, N06-F, N07-4, N09-4) — P3 CONSENSUS MERGE

Seven personas nominated the same low-level accuracy fix across three surfaces (README, CLI reference, changelog). Cartographer correctly merged: one P3 issue across all three surfaces. Real, cheap, correct, but not a launch blocker. Admission + P1 (priority code 1, which is P3).

### Tutorial 1 Setup Path (N05-6, N06-C) — P1 CONSENSUS

The current tutorial (`build-your-first-project.md`) assumes an already-configured project. Tutorial 1 — the setup path through `bootstrap` → `connect` → `install-git-hooks` → `doctor` — does not exist. This is the entry ramp for every new user. Two personas (Believer, Coach) rated this High. Admission + P3 (code 3, which is P1 / "high").

### `spark doctor` Output Format (N00-4, N02-1) — P1/P2 SPLIT

Cartographer's N00-4 asks docs to never quote fabricated output (real strings: `✓ <name>` lines + `Healthy — 0 errors, N warning(s)`). Adopter's N02-1 asks for a full output format spec for scripting/CI. Cartographer explicitly vetoed N02-6 (machine-readable contract inventing a feature not promised). I admit both: N00-4 is a documentation hygiene veto (P1 priority code 2 / P2), and N02-1 is a technical correctness issue (rescopable as Skimmer noted, but not out of scope). Cartographer's veto stands: no invented output.

### GitHub Topics & Awesome-Lists (N10-1, N10-2) — P1 CONSENSUS

These are my own nominations and they're unanimous across the council. Topics are a zero-cost, immediate discoverability lift (implemented by copy/paste into GitHub settings).
