## Skeptic's strongest positions for the Editor

1. **License is the only true P1 with a legal dimension.** Until `LICENSE` holds a
   real SPDX grant, no surface may advertise MIT as adopted. This is not a
   Cartographer veto; the Skeptic's positioning note independently reached the
   same conclusion: the badge is the first thing a developer reads when evaluating
   redistribution. Fix or remove it — both are honest; the current state is not.

2. **`/spark:plan` GitHub integration is a P1 honest-hype failure, not just a
   quickstart polish issue.** The quickstart instructs newcomers to expect
   mechanical GitHub issue creation. Ground truth puts this in v0.3. That is a
   false capability claim on the primary user path. It must be struck before any
   public launch of documentation that describes the Ideate→Plan cycle.

3. **Marketplace caveat is P1 by blast radius.** The README is the only surface
   without the caveat. Every other note — hero, quickstart, positioning, launch
   copy, HN blurb — already carries it. The README is the document most readers
   see first and only. One line added; zero cost; maximum blast-radius reduction.

4. **Philosophy/enforcement-model/authorship-crews is P2, not three P1s.** None
   of these docs existed before this docit run. Their absence is a gap in the docs
   tree, not an active overclaim. They belong in one linked PR, not three
   independent P1 issues. The constraint is: do not publish philosophy until its
   supporting links exist.

5. **OUT votes are scoped, not dismissive.** The GIF, OG image, awesome-list
   submissions, and `launch-copy.md` are legitimate author tasks — they are just
   not GitHub issues for the repo's doc tree. They belong in a launch checklist
   the author works from after the blocking issues close.
