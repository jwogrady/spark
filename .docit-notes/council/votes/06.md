## Coach's binding positions

1. **N06-A (enforcement-model.md) is P1, not P2.** The Believer argues it can be
   deferred; the Coach disagrees. Without enforcement-model.md, philosophy Principle 1
   asserts a design decision that has no rationale document. That is a Diátaxis mode
   violation baked into the first public philosophy doc. Writing the philosophy without
   its prerequisite is shipping a tutorial that references a how-to that doesn't exist.
   P1 stands.

2. **N11-3 (launch-copy.md) is admitted at P2, not dropped.** The Coach contests
   the Cartographer and Coach's own Phase 3 debate note that suggested this is an
   Editor workflow artifact only. The file belongs in `docs/` as a versioned artifact;
   if the docit run produces launch copy and it lives only in scratch notes, it will
   be destroyed on the next run. P2 is appropriate — it is not a launch blocker, but
   it must be created before the docit output chain can be called complete.

3. **N02-6 (machine-readable doctor output contract) is OUT.** The Cartographer's
   contest is correct: there is no evidence a stable machine-readable output contract
   was ever promised. Inventing one is a feature request. The legitimate kernel —
   document the real output strings — is already covered by N00-4/N02-1 merge.

4. **N10-2 (awesome-list submissions) is IN at P2, not OUT.** The Coach's debate
   note contested it as P3; on reflection, P2 is correct because the submissions are
   blocked (correctly) on the license resolution, which means they will naturally
   sequence after the P1 license fix. Admitting at P2 with a hard dependency on the
   license merge is the right posture.
