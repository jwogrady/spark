## Nomination 1

**Title:** README install block has no marketplace-status caveat

**Case:**
The README install section (`## Install`) shows the two slash commands
(`/plugin marketplace add jwogrady/spark` / `/plugin install spark`) with no
qualifier about marketplace availability. Every other surface that cites these
commands — `02-quickstart.md` (cross-eval feedback item 4), `03-positioning.md`
(What Spark concedes), `01-hero.md` (install block), the HN blurb (`11-launch.md`)
— now carries an explicit caveat that the published marketplace listing is a v0.2
open item and that the current verified path is a local clone or Git URL. The
README is the first file a new visitor reads; it is currently the only public-
facing surface that silently asserts the install works as written. If the
marketplace listing is not reachable, a reader following the README will hit a
dead end with no fallback instruction. This is the gap that has the largest
blast radius per the honest-hype contract.

**Provenance:** `03-positioning.md` §"What Spark concedes" (marketplace concession
bullet); `01-hero.md` cross-eval resolution item 3 (marketplace caveat added to
install block); `11-launch.md` tweet 4 and HN caveats. Root evidence:
`00-ground-truth.md` §ROADMAP — "v0.2 open item: validate install end-to-end from
a *published* marketplace (unchecked box)."

**Proposed priority:** P1

## Nomination 2

**Title:** README MIT license badge overclaims an unresolved license

**Case:**
The README header carries `![license](https://img.shields.io/badge/license-MIT-green)`.
The `LICENSE` file reads "License TBD. Copyright belongs to the author." — the
formal license has not been adopted. The manifest (`plugin.json`) also declares
`"license": "MIT"`. Both the README badge and the manifest are aspirational, not
granted. For a developer evaluating whether to incorporate or redistribute Spark,
a green MIT badge on the README sends a legally incorrect signal at first glance.
This surfaces before the reader reaches any trust note or concession section.
`04-trust.md` calls this "the single highest-trust risk in the repo" and recommends
the badge be omitted until the `LICENSE` file is formally updated.
`03-positioning.md` §"What Spark concedes" names it explicitly and advises callers
not to redistribute. The badge and the `LICENSE` file are currently in direct
contradiction.

**Provenance:** `04-trust.md` §"License status" and §"Badge row"; `03-positioning.md`
§"What Spark concedes" (license bullet). Root evidence: `00-ground-truth.md`
§"Accuracy flags" — "`plugin.json` declares `\"license\": \"MIT\"` … the `LICENSE`
file contains only 'License TBD. Copyright belongs to the author.'"

**Proposed priority:** P1

## Nomination 3

**Title:** No `docs/explanation/philosophy.md` — the positioning doc tree is incomplete

**Case:**
`05-philosophy.md` targets a new file at `docs/explanation/philosophy.md` and
declares it must be cross-linked from the `docs/explanation/` index. As of the
current repo state, `docs/explanation/` contains only three files:
`scope-and-upstream.md`, `sdlc-doctrine.md`, `why-a-plugin.md`. There is no
`philosophy.md` and no `docs/explanation/README.md` or index that would link to
one. This is a gap in the positioning story: the values layer (why Spark takes the
stances it does) is in the docit notes but has not been promoted to the public docs
tree. `03-positioning.md`'s honest-delta comparison and the "when to use Spark /
skip it" guidance are orphaned from the docs tree — there is no explanation doc that
a skeptical reader can be directed to for the principled "why." Without the
philosophy doc, anyone reading `scope-and-upstream.md` and `why-a-plugin.md` can
understand the mechanism but not the motivation.

**Provenance:** `05-philosophy.md` §Draft preamble ("Target path:
`docs/explanation/philosophy.md`…cross-link requirement."); `05-philosophy.md`
cross-eval from 06 (Diátaxis) item 2 — "cross-link requirement" resolved but not
yet filed. Root evidence: `00-ground-truth.md` §Docs — `docs/explanation/` lists
`sdlc-doctrine`, `scope-and-upstream`, `why-a-plugin` — no `philosophy.md` in the
verified tree.

**Proposed priority:** P2

## Nomination 5

**Title:** No published comparison or "alternatives" doc — the positioning note in `.docit-notes/03-positioning.md` has no public counterpart

**Case:**
`03-positioning.md` contains the full honest comparison: five alternatives, a
decision table, explicit concessions, and the "use this when / skip it" line. None
of this content is represented anywhere in the public `docs/` tree. The
`docs/explanation/` folder addresses the mechanism (plugin, scope, SDLC doctrine)
but not the competitive posture or the "should I even use this" question. A
developer landing on the repo after seeing the HN post or tweet thread who is
skeptical and wants to read the honest comparison before deciding has no pointer
from the README or the docs index. The comparison table and the "skip it when"
line are the strongest honest-hype artifacts produced by this crew — they belong
in the public docs tree, not locked in a scratch directory. An `explanation/`-tier
doc ("Spark vs. the alternatives" or "When to use Spark") would close this gap.

**Provenance:** `03-positioning.md` §Draft (the full comparison + concessions note
is only in `.docit-notes/`); `00-ground-truth.md` §Docs — no positioning or
comparison doc listed in the verified docs tree. `05-philosophy.md` and `04-trust.md`
cover values and maturity; no doc covers the "vs. alternatives" question.

**Proposed priority:** P2
