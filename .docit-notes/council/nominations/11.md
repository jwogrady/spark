## NOM-11-1: Unresolved license blocks all launch copy from being actionable

**Title:** Adopt a license — MIT badge is an active overclaim that devalues launch copy

**Case:** Every piece of launch copy in `11-launch.md` — the tweet thread, HN blurb, and Reddit post — explicitly calls out the license mismatch as a caveat. Readers who act on the launch copy and look at the repo will find a README badge declaring MIT and a `LICENSE` file that says "License TBD. Copyright belongs to the author." That contradiction undermines trust at the exact moment the launch copy drives traffic to the repo. The Amplifier cannot write honest launch copy that points at a repository whose manifest overclaims an open-source grant it has not made. Fixing the LICENSE file (either adopt MIT properly or remove the badge) is a prerequisite for any launch distribution. This is not a documentation gap — it is a legal overclaim embedded in the repo surface that every launched link exposes.

**Provenance:** `00-ground-truth.md` §"Accuracy flags" — "License mismatch. `plugin.json` declares `"license": "MIT"` and the README badge says MIT, but the `LICENSE` file contains only 'License TBD. Copyright belongs to the author.'"; `04-trust.md` §"License status" — "No enforceable open-source license is in place. Do not incorporate Spark into a project with legal review requirements until a license file is formally adopted."; `11-launch.md` §"HN blurb" claims table — license caveat explicitly flagged in every conversion surface.

**Proposed priority:** P1 — blocks launch. Any distribution of launch copy that drives traffic to a repo with a contradictory license is a reputational and legal risk.
