**CONTEST. Reframe or drop from P1.**

The Adopter (02) nominated this as P1: "`/spark:ship` requires `gh` CLI auth but
it's a hidden prerequisite." The honest-hype concern is real, but the classification
as a P1 issue that blocks the first-win path is overstated. Evidence:

- The Adopter filed two near-identical nominations (N02-3 and N02-5) for the same
  underlying gap ("gh auth is not documented upfront"). N02-5 is explicitly
  self-rated P2. N02-3 claims P1 only by asserting the "complete cycle in one
  session" promise is broken.
- Ground truth does not list `gh` as a prerequisite. The claim that Spark "implies
  a newcomer can complete a full cycle in one session" is a reading of the hero copy,
  not a verified contract.

**Counter:** Merge N02-3 and N02-5 into one P2 issue: "Add prerequisites section to
install how-to, including `gh` CLI auth for `/spark:ship`." This is a how-to
content improvement, not a P1 blocker. Raising a missing `gh auth` note to P1
would classify nearly every developer tool's install guide gap as launch-blocking.
