# Code of Conduct

## The short version

Be direct. Be helpful. Assume good intent. Disagree on ideas, not people.

## Expected behavior

- Communicate clearly and constructively.
- Give and receive feedback on the work, not the person.
- Acknowledge when you are wrong or uncertain.
- Keep discussions on-topic.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Deliberate intimidation or hostility.
- Publishing others' private information without consent.

## Scope

This applies in all project spaces: GitHub issues, PRs, discussions, and any
other venue where contributors interact on behalf of this project.

## Enforcement

Violations may result in a warning or removal from the project at the
maintainer's discretion.
