## Versioning note

Unlike v0.10 (whose `v0.10.0` cut before the milestone was complete, forcing the
rest into `v0.10.1`/`.2`), v0.11 was released **once, at completion**: the four
`feat:` PRs bumped `0.10.2 → 0.11.0` naturally, so the milestone label and the
release version stayed in lockstep with no `Release-As` pin. This is the
milestone-as-version-line discipline working as intended.

## First release verified through the milestone gate

`v0.11.0` is the first release to pass end to end through the mechanisms built in
v0.10.1: the Release Please PR was created under the `RELEASE_PLEASE_TOKEN`
identity, so `validate` (doctor + tests) ran on it unheld, and the
`milestone-gate` reached **ready** — every mapped milestone issue closed and
validation green — before the human approved the merge.

## Validation evidence

- `spark doctor` — Healthy 0/0, including the new orient, standards-boundary, and
  skills-taxonomy checks, with a clean doc-link scan.
- `tests/run.sh` — all 18 suites pass, adding `test-orient.sh`,
  `test-standards-docs.sh`, `test-doctor-standards-boundary.sh`, and
  `test-first-run.sh`, plus new cases in `test-brief-resume.sh`.
- Behavioral coverage spans clean-dir, empty-Git, mature, imported, and ambiguous
  repository fixtures (shared builders in `tests/lib.sh`).
- Existing project files are preserved: `spark setup` is create-only and reports
  `+ created / = kept / ! needs a decision`, proven in the adopt-existing tutorial
  and the standards-docs tests.

## Boundaries held

- Generated standards are readable, editable, and **non-executable** prose;
  only explicitly `spark:pref`-marked lines are machine-backed, and the doctor
  check guards that seam. Prose never silently becomes configuration.
- `.spark/state.json`'s eight-key schema stayed frozen; the classification fact
  lives in `.spark/preferences.json`.
- No orchestration / model-selection architecture was introduced — that is
  reserved for #190 and v0.12.

## Result

All milestone sub-issues (#183, #182, #199, #200, #201, #202) are closed; #197
closes with this record. No scope was deferred out of v0.11.
