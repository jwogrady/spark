## Versioning note

`v0.10.1` includes one `feat:` (#188) yet ships as a patch. That is deliberate:
the `v0.10.0` release was cut before the milestone was complete, so the
remaining milestone work is pinned into the `0.10.x` line (`Release-As: 0.10.1`)
to keep the milestone label and the release version aligned, rather than
advancing to `0.11.0`. Future milestones map one-to-one to a release cut only
once the milestone is complete.

and GitHub Releases (ADR-0006, ADR-0009, ADR-0016). Token-failure behavior is
