## Why this milestone cuts no version

`master` already carries the cumulative implementation through the reconstructed
v0.19 outcome. A fresh `v0.18.0` would therefore be a governance-only release
whose implementation had already gone out inside an earlier tag — the
release/scope mismatch that the 2026-08-26 rollback corrected.

The implementation is **not deferred and not lost**. It reaches the public once,
inside the cumulative **`v0.19.0`** catch-up release, gated by #445. See
`v0.19.md`.

## One outcome, three publications

The withdrawn v0.18.x train published one coherent outcome three times:
`v0.18.0` carried the issue-backed first-run and governance work, while
`v0.18.1` and `v0.18.2` carried release-convention documentation and hardening
follow-ups to fixes already in `v0.18.0`. That split was an artifact of
publishing cadence, not of architecture, so the reconstruction collapses it into
this single milestone.
