shimmed = invocations of a fixed shim list — a LOWER BOUND on subprocesses,
not a full accounting. parsers = the awk/sed/grep/cut/tr subset. gh = gh
invocations, NOT HTTP requests: one invocation may make several.

mode=live means the path invoked gh, so its wall time depends on the network
and on live GitHub state. Live rows are observational, not a reproducible
baseline; compare offline rows against the same machine, never across hosts.
