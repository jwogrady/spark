# Reviewer finding text of record (#730 baseline)

`pr727/findings.txt` and `pr724/findings.txt` hold every finding bullet of the independent reviewer
(`github-actions[bot]`, `spark-openai-review` markers) for PR #727 rounds 1–16 and PR #724 rounds 1–32,
copied **verbatim and complete** from the GitHub comments named in each round header (comment id, HEAD,
verdict, time). They are the immutable input to `raw/findings-classification.tsv` in the #730 analysis
bundle (PR #747); finding ids are `<round>.<bullet>`. Generated by `tools/dump-findings.py` from the raw
comment JSON fetched with `tools/fetch-pr.sh`. Measurement evidence only; nothing here changes Spark.
