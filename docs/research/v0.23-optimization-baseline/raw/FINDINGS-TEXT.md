# Reviewer finding text of record (#730 baseline)

`pr727/findings.txt` and `pr724/findings.txt` hold every finding bullet of the independent reviewer
(`github-actions[bot]`, `spark-openai-review` markers) for PR #727 rounds 1–16 and PR #724 rounds 1–32,
copied **verbatim and complete** from the GitHub comments named in each round header (comment id, HEAD,
verdict, time). Record format: a `### <round>.<bullet>` line is a **synthetic id envelope**; the lines after it,
up to the next `###`/`##`, are the original top-level bullet block **byte-for-byte** (the `- ` line plus its
continuation lines, indented sub-bullets and internal blank lines). The envelope is not part of the finding.
`findings-validation.txt` beside each file is the output of `tools/validate-findings.py`, which re-fetches every
cited comment with `gh api`, removes the envelope line and the writer's trailing newline, normalizes the body
CRLF→LF and nothing else, and proves that each block is a verbatim substring of that body and that the top-level
bullet counts agree. They are the input to
`raw/findings-classification.tsv` in the #730 analysis bundle (PR #747); finding ids are `<round>.<bullet>`.
Generated by `tools/dump-findings.py` from the raw comment JSON fetched with `tools/fetch-pr.sh`. Measurement
evidence only; nothing here changes Spark.
