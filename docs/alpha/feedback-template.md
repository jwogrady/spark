## Mistakes & recovery

- Did you make a mistake (wrong branch, bad commit, wrong push, etc.)?
- Did a guard or hook stop you? Was its message clear and actionable?
- Could you recover? How long did it take?

## Documentation

- **Which docs did you open** (before asking for help)?
- **Did they answer you?**
- **Which docs did you never open** even when stuck?

## Companions (if used)

- Which of `spark-audit` / `spark-connect` / `spark-docs` did you use?
- Did you know *when* to reach for it vs the core?
- Was its boundary vs the core clear?

## Value (the questions that matter most)

- **Did Spark save you time on this run, cost you time, or break even?**
- **Did it prevent a mistake you'd otherwise have made?**
- **Did it improve your planning or the quality of what you shipped?**
- **On a second/third run — is it still worth it, or is the overhead showing?**
