# v0.13 mechanical-step offload audit (#210)

Which model-performed steps in the shipped skills are *mechanical* — their
correct output is fully determined by their inputs — and therefore belong in a
deterministic helper, versus which are judgment and stay prompted. Judgment
stays with the model; a step is offloaded only when no script could get it wrong.

Measurement method and the footprint numbers are `spark footprint` (#208); the
size budgets are enforced by `spark doctor` (#209).

## Evidence table

| Skill(s) | Mechanical step | Disposition |
|---|---|---|
| ideate, plan, codify, validate, ship | Write `.spark/state.json` at close-out — valid one-level JSON, stamp `updated`, keep the key set stable | **Offloaded** → `spark state --set key=value …`. The skill supplies the judgment values (issue, blockers, next action); the writer handles formatting/stamping/merge. |
| all skills + companions | Frontmatter validity, description budget, doc-link resolution | **Already offloaded** (pre-#210) → `spark doctor` (`lint_skill_md`, broken-link scan). No per-skill model step remains. |
| plan | GitHub issue/milestone wiring, metadata-header formatting | **Deferred → #214** (the deterministic manifest helper for issue wiring is its own milestone issue; not duplicated here). |
| codify | Readiness preflight (branch/issue/working-tree facts before implementing) | **Kept-prompted.** The *facts* are already scriptable and surfaced by `spark brief`/`resume`; the readiness *decision* (is this issue ready, is scope clear) is judgment. No new bundle script earns its place over the existing brief. |
| validate | Triage setup (running the built-in reviews, ordering findings) | **Kept-prompted.** The reviews are native capability (`/code-review`, `/security-review`, `verify`) already; triaging their findings is judgment. Nothing mechanical to extract. |
| onboard, bootstrap, knowledge, agents-md, audit, connect, docit | Narrative/generation/classification steps | **Kept-prompted.** Each produces a judgment-shaped artifact, not a single determined output. |

## Footprint delta (recorded on #207)

Baseline (#208, pre-optimization): core **72,022 B / ~18,004 tokens**.

After #209 (budgets + agents-md relocation) and #210 (state writer): core
**73,133 B / ~18,283 tokens** — a small *increase* in **total** on-disk
footprint. This is the honest and expected shape of progressive disclosure:
moving agents-md depth from its `SKILL.md` body into `references/` lowers the
**always-on-invoke** body surface (skills: 37,927 → 37,414 B) but the relocated
text still exists on disk under `references/` (20,076 → 21,700 B), and a
reference file carries its own framing. Progressive disclosure changes *when* a
surface is paid, not the total that exists.

The two levers that reduce the total — not merely relocate it — are removing
content that no longer earns its place and right-sizing the crew roles (#211).
The #210 change itself is size-neutral; its win is determinism: five skills no
longer hand-format a JSON file that silently drifts from the schema.
