# grill-me

Relentlessly interviews the user about a plan or design until reaching shared
understanding. Walks down each branch of the decision tree, resolving
dependencies one-by-one. Provides a recommended answer for each question.

## When to use

Invoke when the user wants to stress-test a plan, get grilled on a design, or
says "grill me".

## Behavior

- Asks questions one at a time
- Provides a recommended answer with each question
- Explores the codebase to answer questions that can be resolved from code
  rather than asking the user
