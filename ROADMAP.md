# Roadmap

This roadmap reflects current intent, not a commitment or timeline.
Priorities may shift as the project evolves.

---

## v0.2 — Plugin + lifecycle

**Status:** In progress

Spark becomes a Claude Code plugin organized around the
`Ideate → Plan → Generate → Solve → Ship` lifecycle.

- [x] Plugin packaging: `.claude-plugin/plugin.json` + `marketplace.json`
- [x] Lifecycle skills: `ideate`, `plan`, `codify`, `fix-issue`, `ship`
- [x] Supporting skills: `agents-md`, `bootstrap`, `connect`, `review`, `docit`, `knowledge`
- [x] Enforcement: PreToolUse guard (force-push / push-to-trunk) + git hooks
      (`commit-msg`, `pre-commit`)
- [x] `spark` CLI: `doctor`, `list-skills`, `new-skill`, `install-git-hooks`, `shred-env`
- [x] Documentation reorganized to Diátaxis
- [ ] Validate install end-to-end from a published marketplace

---

## v0.3 — Plan ↔ GitHub

**Status:** Planned

Tighten the Plan stage's GitHub integration:

- Generate issues and a milestone directly from a problem statement
- Keep issue drafts and GitHub state in sync
- Wire acceptance criteria through to the Solve stage's definition of done

---

## v0.4 — Subagents and MCP

**Status:** Planned

- Bundle reusable subagents (`agents/`) for review and exploration tasks
- Optional bundled MCP servers (`.mcp.json`) for common integrations

---

## v0.5 — Stack-aware setup

**Status:** Planned

- A `spark setup` flow that proposes a curated permission baseline per stack
- Stack-specific `CLAUDE.md`/`AGENTS.md` presets generated by the existing skills

---

## Later — Project inception

Project inception — `/plugin install spark` plus the `bootstrap` skill —
graduates into a guided "scaffold a new project from Spark" flow, distinct from
plain distribution (which carries the toolkit into existing projects).
